# 任务1：创建第一个Kotlin应用

## 1. 实验目标

本次任务是创建一个基于 Kotlin 语言的 APP，并使用 Jetpack Compose 来管理 UI。通过本次任务，我学习到了：

- 如何在 Android Studio 中创建新的 Kotlin 项目
- 如何使用 Jetpack Compose 构建用户界面
- Compose 编程的基础概念和语法

## 2. 创建项目

### 2.1 打开 Android Studio

打开 Android Studio 开发工具。

### 2.2 创建新项目

在 Android Studio 主界面，选择 **New Project** 来创建一个新的应用项目。

### 2.3 选择项目模板

在 **Phone and Tablet** 选项卡中，找到并选择 **Empty Activity** 模板。这是创建一个空白 Compose 应用的基础模板。

### 2.4 配置项目信息

将项目命名为 **MyFirstKotlinApp**，包名保持默认，语言选择 **Kotlin**，最小支持 SDK 选择 **API 21**（这是 Compose 支持的最低版本）。

### 2.5 完成创建

点击 **Finish** 完成项目创建。Android Studio 会自动配置 Gradle 和依赖项。

## 3. 项目结构

创建完成后的项目结构如下：

```
MyFirstKotlinApp/
├── app/
│   ├── src/
│   │   ├── main/
│   │   │   ├── java/com/example/myfirstkotlinapp/
│   │   │   │   ├── MainActivity.kt          # 主活动文件
│   │   │   │   └── ui/theme/                # 主题相关文件
│   │   │   │       ├── Theme.kt            # Compose 主题配置
│   │   │   │       ├── Color.kt             # 颜色定义
│   │   │   │       └── Type.kt              # 字体样式定义
│   │   │   ├── res/                         # 资源文件夹
│   │   │   └── AndroidManifest.xml          # 应用清单文件
│   │   └── build.gradle.kts                  # 应用级构建配置
├── build.gradle.kts                         # 项目级构建配置
└── settings.gradle.kts                      # 项目设置
```

## 4. 代码解析

### 4.1 MainActivity.kt 主活动文件

MainActivity.kt 是应用的主入口文件，负责设置 Compose UI 内容。以下是核心代码：

```kotlin
package com.example.myfirstkotlinapp

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Scaffold
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.tooling.preview.Preview
import com.example.myfirstkotlinapp.ui.theme.MyFirstKotlinAppTheme

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            MyFirstKotlinAppTheme {
                Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                    Greeting(
                        name = "Android",
                        modifier = Modifier.padding(innerPadding)
                    )
                }
            }
        }
    }
}
```

#### 4.1.1 ComponentActivity 继承关系

MainActivity 继承自 `ComponentActivity`，这是 Jetpack Compose 的基础 Activity 类，提供了 Compose UI 的集成支持。

#### 4.1.2 onCreate 生命周期方法

`onCreate()` 是 Activity 的生命周期方法，在应用启动时首次调用：

- `super.onCreate(savedInstanceState)`：调用父类的 onCreate 方法
- `enableEdgeToEdge()`：启用边缘到边缘的显示模式，让内容延伸到系统栏下方
- `setContent {}`：设置 Compose UI 的入口点

#### 4.1.3 setContent UI 入口

`setContent {}` 是 Compose 的核心函数，用于定义 UI 界面。所有 Compose UI 元素都必须在 `setContent` 块内部定义。

#### 4.1.4 MyFirstKotlinAppTheme 主题包装

`MyFirstKotlinAppTheme` 是一个自定义的 Compose 主题函数，用于：

- 设置应用的色彩方案（深色/浅色模式）
- 配置 Material 3 设计系统
- 提供全局的 UI 样式

#### 4.1.5 Scaffold 布局容器

`Scaffold` 是 Material 3 提供的布局组件，提供了标准的 Material Design 界面结构：

```kotlin
Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
    // innerPadding：系统栏和导航栏的间距
    Greeting(name = "Android", modifier = Modifier.padding(innerPadding))
}
```

### 4.2 @Composable 注解

`@Composable` 是 Compose 的核心注解，用于标记可组合的函数：

```kotlin
@Composable
fun Greeting(name: String, modifier: Modifier = Modifier) {
    Text(
        text = "Hello $name!",
        modifier = modifier
    )
}
```

**特点：**

- `@Composable` 修饰的函数必须遵循特定的调用规则
- 这些函数只能在其他 `@Composable` 函数或 `setContent` 中调用
- 每次状态变化时，函数会被重新调用以更新 UI

### 4.3 @Preview 实时预览

`@Preview` 注解用于在 Android Studio 中实时预览 Compose UI：

```kotlin
@Preview(showBackground = true)
@Composable
fun GreetingPreview() {
    MyFirstKotlinAppTheme {
        Greeting("Android")
    }
}
```

**属性说明：**

- `showBackground = true`：显示背景色
- 预览函数可以独立于设备或模拟器运行
- 便于快速迭代和调试 UI 设计

## 6. 知识点总结

| 概念 | 说明 |
|------|------|
| **Jetpack Compose** | Android 的现代 UI 工具包，使用声明式编程方式构建 UI |
| **@Composable** | 标记函数为可组合函数，用于定义 UI 元素 |
| **@Preview** | 预览注解，用于在开发环境中实时查看 UI 效果 |
| **ComponentActivity** | Compose 应用的基础 Activity 类 |
| **setContent** | 设置 Compose UI 内容的入口函数 |
| **Scaffold** | Material 3 布局容器，提供标准界面结构 |
| **MyFirstKotlinAppTheme** | 自定义主题，配置应用的色彩和样式 |
