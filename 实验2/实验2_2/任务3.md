# 任务3：面向AI应用的Compose布局实践

## 1. 实验目标

本次任务是完成面向AI应用的Compose布局实践，创建一个AI图像识别应用界面。通过本次任务，我学习到了：

- 使用 `Scaffold` 构建标准的 Material Design 界面结构
- 创建自定义的 `TopAppBar` 顶部导航栏
- 使用 `Card` 组件展示识别结果信息
- 组合多种布局组件实现复杂界面
- 自定义 `ActionButton` 组件并复用

## 2. 创建项目

在 Android Studio 中创建一个名为 **AI_compose** 的新项目，选择 Empty Activity 模板，语言选择 Kotlin，最小支持 SDK 选择 API 21。

## 3. 核心代码实现

### 3.1 主界面结构

```kotlin
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            AI_composeTheme {
                Scaffold(
                    topBar = { TopAppBar() },
                    modifier = Modifier.fillMaxSize()
                ) { innerPadding ->
                    MainContent(modifier = Modifier.padding(innerPadding))
                }
            }
        }
    }
}
```

### 3.2 顶部导航栏

```kotlin
@Composable
fun TopAppBar() {
    Row(
        modifier = Modifier
            .fillMaxWidth()
            .height(56.dp)
            .background(Color(0xFF1E88E5)),
        horizontalArrangement = Arrangement.SpaceBetween,
        verticalAlignment = Alignment.CenterVertically
    ) {
        Text(
            text = "LiteRT AI Demo",
            color = Color.White,
            fontSize = 20.sp,
            fontWeight = FontWeight.Bold,
            modifier = Modifier.padding(start = 16.dp)
        )
        IconButton(onClick = {}) {
            Icon(
                imageVector = Icons.Default.MoreVert,
                contentDescription = "More options",
                tint = Color.White
            )
        }
    }
}
```

### 3.3 主内容区域

```kotlin
@Composable
fun MainContent(modifier: Modifier = Modifier) {
    Column(
        modifier = modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        CameraPreviewSection()
        ResultSection()
        ButtonSection()
    }
}
```

### 3.4 自定义ActionButton组件

```kotlin
@Composable
fun ActionButton(
    text: String,
    icon: ImageVector,
    backgroundColor: Color,
    modifier: Modifier = Modifier
) {
    OutlinedButton(
        onClick = {},
        modifier = modifier
            .height(48.dp)
            .background(backgroundColor, RoundedCornerShape(8.dp))
            .border(0.dp, Color.Transparent, RoundedCornerShape(8.dp)),
        shape = RoundedCornerShape(8.dp)
    ) {
        Row(
            horizontalArrangement = Arrangement.Center,
            verticalAlignment = Alignment.CenterVertically,
            modifier = Modifier.fillMaxWidth()
        ) {
            Icon(imageVector = icon, contentDescription = text, tint = Color.White)
            Text(text = text, color = Color.White, modifier = Modifier.padding(start = 8.dp))
        }
    }
}
```

## 4. 核心知识点解析

### 4.1 Scaffold 布局容器

`Scaffold` 是 Material 3 提供的标准界面结构容器：

```kotlin
Scaffold(
    topBar = { TopAppBar() },  // 顶部导航栏
    modifier = Modifier.fillMaxSize()
) { innerPadding ->
    MainContent(modifier = Modifier.padding(innerPadding))  // 主内容区域
}
```

### 4.2 Card 组件

`Card` 组件用于展示卡片式内容：

```kotlin
Card(
    elevation = CardDefaults.cardElevation(defaultElevation = 4.dp),
    shape = RoundedCornerShape(12.dp)
) {
    // 卡片内容
}
```

### 4.3 自定义组件复用

通过创建 `ActionButton` 组件实现代码复用：

```kotlin
ActionButton(text = "拍照识别", icon = Icons.Default.CameraAlt, backgroundColor = Color(0xFF1E88E5))
ActionButton(text = "相册导入", icon = Icons.Default.Photo, backgroundColor = Color(0xFF43A047))
ActionButton(text = "切换模型", icon = Icons.Default.Refresh, backgroundColor = Color(0xFF8E24AA))
ActionButton(text = "清空结果", icon = Icons.Default.Delete, backgroundColor = Color(0xFFE53935))
```

## 5. 界面布局结构

| 区域 | 组件 | 功能 |
|------|------|------|
| TopAppBar | Row + Text + IconButton | 顶部导航，显示应用名称和更多选项 |
| CameraPreviewSection | Box + Column + Icon + Text | 相机预览占位区域 |
| ResultSection | Card + Column + ResultRow | 识别结果展示卡片 |
| ButtonSection | Column + Row + ActionButton | 功能按钮区域 |

## 7. 知识点总结

| 概念 | 说明 |
|------|------|
| `Scaffold` | Material 3 标准界面结构容器 |
| `Card` | 卡片式内容展示组件 |
| `OutlinedButton` | 带边框的按钮组件 |
| `Icon` / `IconButton` | 图标和图标按钮组件 |
| 自定义可组合函数 | 通过 `@Composable` 创建可复用组件 |
